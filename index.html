Rig Lab

Write movement code on the right. The rig on the left performs it, joint by joint.

Joint & command reference

Joints (degrees, 0 = hanging straight down):
leftShoulder, rightShoulder, leftElbow, rightElbow,
leftHip, rightHip, leftKnee, rightKnee

Commands (all can be awaited):

  • setJoints({ joint: angle, ... }, ms) — animate one or more joints together
  • setBody({ x, y, rot }, ms) — move / rotate the whole rig (for jumps, flips)
  • wait(ms) — pause without moving
  • resetPose(ms) — return every joint and the body to rest

Ordinary JavaScript works too — for loops, variables, functions.
